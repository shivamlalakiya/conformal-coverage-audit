========================================================================================================
WHAT THIS DOES NOT SETTLE
========================================================================================================
Nothing here rules on a site. The screen puts a ceiling on the missed
set and settles no package inside it; ruling means reading one expression
at a time against the criterion, and this sweep read none that way.

Arm A cannot see a conformal library named after an ordinary word, and
the recall block measures exactly how badly. Arm B cannot see anything
below its floor, which is where every conformal-first package lives.
Between them they bound the gap; neither closes it, and a package that
publishes no metadata at all is outside both.

The index moves. Names are added daily and download ranks turn over, so
a re-run will not reproduce these counts exactly. The date above is the
claim's scope.
