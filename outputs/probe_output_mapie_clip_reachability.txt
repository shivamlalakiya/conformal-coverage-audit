VERDICT
--------------------------------------------------------------------------------------------
  The clip is REACHABLE through the public API. The guard that makes it dead code
  is skipped by the same flag the caller sets to opt into infinite bounds
  (regression/regression.py:1714, 'if not allow_infinite_bounds:'), and
  TimeSeriesRegressor passes allow_infinite_bounds=True internally
  (regression/time_series_regression.py:319), so a caller who never sets the flag
  can still reach it.

  Direction: ANTI-CONSERVATIVE. A finite interval is returned where no valid finite
  deterministic bound exists, so it under-covers. The caller asked for an infinite
  bound and received a silently clamped finite one.

  What the earlier scan established, and still establishes: on the DEFAULT path,
  allow_infinite_bounds=False, the guard raises before the clip and the clip is
  dead. That scan was right about the path it scanned. It did not vary this flag.
