Reading this table
------------------
puncc is the control: it appends +inf and takes the inverted_cdf, so it lands
on the same order statistic as arm B and the delta must be exactly zero. Any
other reading there is a harness bug, not a library defect.

'refused_by_guard' is a PASS, not a failure. A library that raises where no
valid bound exists is behaving correctly; the branch to worry about is the one
that returns a finite interval there instead.

A NEGATIVE delta means the shipped interval covers MORE than the required
rank -- conservatism, not a defect. mapie's asymmetric rails split alpha across
two tails and so land wider than the symmetric bound arm B builds. Do not
write that up as undercoverage.
