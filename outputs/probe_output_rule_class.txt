====================================================================================================
THE LEVEL-RESOLVING RULE CLASS: FINITELY PARTITIONED, AND MINIMAX-SOLVED
====================================================================================================
self_check() passed at import. It checks the reduction against the rules run
as written -- form the level, form h, round -- for every definition, both
corrections and four levels, over 4d consecutive sizes above the prefix. It
also checks that a U drawn off every grid point lands in an enumerated cell,
that one residue does NOT separate the class, and that the validity filter
and the policy axis both discriminate.

THE CLASS.  h(q, n) = a0 + a1 n + q (b0 + b1 n), rational coefficients, then
a rounding policy from ceil, floor, half_even, half_up, trunc, optionally the
level correction q -> min(1, q(n+1)/n), optionally a clip into [1, n].

THE REDUCTION.  At a fixed level L = p/d in lowest terms, h is affine in n:
h = U + V n with U = a0 + L b0 and V = a1 + L b1. Bounded over-coverage
forces V = L, since delivered coverage is rank/(n+1) -> V. Writing
L n = floor(Ln) + f, gcd(p,d) = 1 makes f sweep all of {0, 1/d, .., (d-1)/d},
and delivered - required = P(U + f) - ceil(f + L). So a rule's whole
observable behaviour above the prefix is 2d integers, indexed by n mod 2d.

The period is 2d and not d because round-half-to-even breaks a tie on the
parity of the FULL integer part, which the offset alone does not carry. Only
that policy needs the doubling; the others repeat with period d inside it. A
draft rounded on the offset alone and its self-check caught `nearest` at
n = 26, L = 9/10, where h = 23.5 rounds up because 23 is odd while the offset
0.5 rounds down because 0 is even.

Integer offsets are enumerated over |m| <= 2: a rule delivering more
than 2 ranks past the requirement is not a candidate for resolving
the level, and the bound is stated rather than left implicit.

====================================================================================================
(2) EXACTNESS IS ATTAINABLE, AND ONE SHIPPED CONVENTION ATTAINS IT
====================================================================================================
A cell with deficit 0 at every residue delivers the required rank at EVERY
size. The class contains one at every level and under every rounding policy,
so the question is not whether exactness is reachable but which conventions
reach it.

A RETRACTED READING, RECORDED BECAUSE IT WAS PLAUSIBLE. A draft of this probe
claimed exactness required a unit-fraction alpha. That is true of ONE rule and
false of the class. The rule h = q(n+2) with floor -- the natural-looking
affine candidate -- has U = 2L, and the exact offsets under floor form the
interval [2 - (d-p+1)/d, 2 - (d-p)/d), which contains 2L exactly when p = d-1,
that is when alpha = 1/d. So the unit-fraction trap is real and it is about
that rule. Generalising it to the class was the error, and the assertion that
caught it compared the claim against the enumeration rather than against my
derivation.

THE WITNESS THAT WORKS AT EVERY LEVEL is shorter than any of this:

    required rank = ceil( q (n+1) )

the mean-rank plotting position's own virtual index, rounded UP instead of
down. It is exact by construction, since ceil(L(n+1)) IS the required rank,
and it sits in the class at a0 = a1 = 0, b0 = b1 = 1, policy ceil. numpy
pairs that index with linear interpolation and calls it `weibull`; it pairs
`higher` with a different index. And one shipped combination already IS this
rule, by an identity worth stating: `inverted_cdf` computes ceil(q n), so at
the corrected level q = L(n+1)/n it computes ceil(L(n+1)) -- the required rank,
exactly, at every size and every level. The correction and the convention
compose into the answer. That is not the idiom either paper recommends.

====================================================================================================
(4) THE PREFIX, STATED RATHER THAN ASSUMED AWAY
====================================================================================================
The correction q -> q(n+1)/n leaves a L*b0/n term in h, so the reduction
holds above a prefix and not below it. The term cannot move a rounding
boundary once it is under the grid spacing 1/d, giving n > |L b0| d. Sizes
below that are irregular and are excluded by measurement, not by assumption:

practitioner writes, so it is run: for each size and level, numpy is asked for
the corrected level and the answer is compared to the required order statistic

software is not evidence about shipped software -- and running it changed the
recommendation a second time.

Every miss sits at a size where L(n+1) is an INTEGER: the required rank is
attained with no slack, the corrected level L(n+1)/n is not a double, and the
product recovers 28.000000000000004 rather than 28, so ceil returns 29. The
mechanism is representation, not the convention, and it strikes only where the
rule is tight. The exposure is bounded above by how often the level leaves no
slack. WHICH of those sizes actually fail is decided by the binary expansion of
the corrected level and is not predictable from alpha: the no-slack sizes at
alpha = 1/10 and 1/20 all came out exact, and the misses are concentrated at
2/7, 1/3 and 1/2. We do not offer a characterisation, because we do not have
one -- and not having one is the argument. A level is a lossy channel for an
integer even when the convention on the far side is the right one.

WHICH IS THE ANSWER, AND IT IS NOT A LIBRARY CALL:

    numpy.sort(scores)[k - 1],    k = ceil((n+1)(1-alpha))

exact at every size and level tested, by construction, because no level is
formed. The best available library idiom is

    numpy.quantile(scores, min(1, (1-alpha)*(n+1)/n), method='inverted_cdf')

which is minimax-optimal among conventions and conservative by one rank at the
sizes with no slack. Both manuscripts recommended `higher` at the same level,
which is valid and one rank wide on a whole residue class rather than on a
handful of unrepresentable sizes. That recommendation is superseded here.


====================================================================================================
WHAT THIS DOES NOT SETTLE
====================================================================================================
The class is affine in the level with coefficients affine in the size. A rule
whose index is quadratic in n, or which consults the scores themselves, is
outside it and is not covered by the certificate. Randomised rules are
outside it by construction -- they are the subject of the companion's
randomised-bound section, where the feasibility floor moves. And the minimax
is over WORST-CASE over-coverage across sizes; a rule minimising average
over-coverage against a distribution over n is a different optimisation and
is not solved here.
