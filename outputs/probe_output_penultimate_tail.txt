THE TAIL LAW OFF THE EXACT-GPD HYPOTHESIS
====================================================================================================
self_check() passed at import: the local shape of a GPD is its own shape to
1e-4; d(pi)/d(xi) approaches gamma(1-gamma)/i and the approach is monotone
in depth; and the predicted signs hold for the normal and the lognormal.

The claim. The first-order rate is pi = gamma + gamma(1-gamma)(1+xi)/i, and
its xi-derivative is gamma(1-gamma)/i, which to leading order does not
depend on xi. A first-order shape perturbation therefore enters pi through
that single coefficient, so replacing xi by the shape the sample sees at its
own depth carries the law off the exactly-GPD hypothesis:

    pi = gamma + gamma(1-gamma)(1 + xi_n)/i + o(1/i),   xi_n = xi + A(n/i)/rho

(5) THE REMAINDER, WITH A CONSTANT
An early draft stopped at an unbounded O(1/i^2), on the view that a bound
nobody can evaluate is ornament. Wrong instinct here: establishing safety
in the limit earns its place whether or not data can compute the constant.
So it is derived.

    pi = gamma + c1/i + c2/i^2 + O(1/i^3)
    c1 = gamma(1-gamma)(1+xi)
    c2 = -gamma(1-gamma)(1+xi)(2*gamma*xi + gamma - xi)

Hence for |xi| <= X, since gamma(1-gamma) <= 1/4:
    |pi - gamma - c1/i| <= C/i^2 + O(1/i^3),  C = (1+X)(1+3X)/4
    at X = 1 that is C = 2.00

(5b) THE MEAN VALUE STEP, WITH A PROOF INSTEAD OF A GRID
An earlier draft took the mean value theorem in xi across the segment from
the asymptotic shape to the penultimate one, justified by calling the
leading coefficient gamma(1-gamma)/i uniform. We had checked that on a grid
and not proved it, and the grid was right while the reasoning was not:
d(pi)/d(xi) = (i+1) E[exp(-phi) t^2 h(xi t)] and sup_u h EXCEEDS its value
at u = 0. So the leading coefficient is not itself a bound. What is a bound,
and needs two lines rather than a grid:

    phi = log(A)/xi,  A = (1-g) + g e^{xi t},  d(phi)/d(xi) = t^2 h(xi t)
    h(u) = psi(u)/u^2,  psi(u) = u*sigma(u) - log A,  sigma = g e^u / A
    psi(0) = 0  and  psi'(u) = u*sigma(u)(1-sigma(u))     [an identity]
    sigma(1-sigma) <= 1/4  =>  0 <= psi(u) <= u^2/8  =>  0 <= h <= 1/8
    0 < exp(-phi) <= 1,  E[t^2] = 2/i^2  =>  0 <= d(pi)/d(xi) <= (i+1)/(4i^2)

uniform in xi over ALL of R and in gamma over (0,1), with no asymptotics.
Which turns the mean value step into an inequality, not an expansion:
    |pi - pi_GPD(xi)| <= |xi_n - xi| * (i+1)/(4i^2)
with xi_n - xi = A(n/i)/rho + o(A) the domain-of-attraction hypothesis, so
every remaining error term sits there and none in this step.

(6) CONVERGENCE OF pi TO gamma BY DOMAIN OF ATTRACTION
How fast interpolation stops mattering, and how that depends on tail
heaviness. The rate is c1/i = gamma(1-gamma)(1+xi)/i, so the DOMAIN sets the
constant: heavier tail, larger xi, slower convergence -- and in the Weibull
domain at xi = -1 there is nothing to converge, because pi = gamma already.

At gamma = 1/2 the departure at depth 5 runs from exactly zero in the
bounded-tail case up to the Frechet figure above. Same fraction, same

of interpolation as a mere O(1/n) effect: the constant IS the shape index
no amount of data moves it.

What this buys, and what it does not. The exactly-GPD hypothesis is no
longer the boundary of the result: the rate holds off it with xi read as the
shape at the sample's own depth, to first order in the second-order
auxiliary. Those fitted signs -- below zero for the normal, above it for
the lognormal, both heading in -- stop being something noticed and turn
into something xi_loc predicts with no sample involved. Not claimed: any
statement bounding what is left at o(1/i) in evaluable terms. That would
be ornament, and what stands in for it is the departure measured
above.
